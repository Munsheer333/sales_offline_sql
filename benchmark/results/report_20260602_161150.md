### Query 6: Which company has the lowest market share in fiscal year 2024-2025?
- **Pipeline Success**: `True`
- **Execution Correctness (DB Match)**: `True`
- **Duration**: `83.07 ms`
- **Expected SQL**:
  ```sql
  WITH company_sales AS (SELECT comname, SUM(netweight_tmt) AS company_total FROM industry_performance WHERE (category != 'O' OR category IS NULL) AND fiscal_year = '2024-2025' GROUP BY comname), total_market AS (SELECT SUM(netweight_tmt) AS market_total FROM industry_performance WHERE (category != 'O' OR category IS NULL) AND fiscal_year = '2024-2025') SELECT cs.comname, ROUND((cs.company_total * 100.0) / tm.market_total, 2) AS market_share_percentage FROM company_sales cs CROSS JOIN total_market tm ORDER BY market_share_percentage ASC LIMIT 1;
  ```
- **Generated SQL**:
  ```sql
  WITH company_sales AS (
    SELECT industry_performance.comname, SUM(industry_performance.netweight_tmt) AS company_total
    FROM industry_performance
    WHERE (industry_performance.category != 'O' OR industry_performance.category IS NULL) AND industry_performance.fiscal_year = '2024-2025'
    GROUP BY industry_performance.comname
),
total_market AS (
    SELECT SUM(industry_performance.netweight_tmt) AS market_total
    FROM industry_performance
    WHERE (industry_performance.category != 'O' OR industry_performance.category IS NULL) AND industry_performance.fiscal_year = '2024-2025'
)
SELECT company_sales.comname,
       ROUND((company_sales.company_total * 100.0) / NULLIF(total_market.market_total, 0), 2) AS market_share_percentage
FROM company_sales
CROSS JOIN total_market
ORDER BY market_share_percentage ASC
LIMIT 1;
  ```
