- **Pipeline Success**: `True`
- **Execution Correctness (DB Match)**: `False`
- **Duration**: `87.68 ms`
- **Expected SQL**:
  ```sql
  WITH y1 AS (SELECT SUM(netweight_tmt) AS s1 FROM industry_performance WHERE comname = 'HPCL' AND sbu_name = 'Retail' AND fiscal_year = '2023-2024'), y2 AS (SELECT SUM(netweight_tmt) AS s2 FROM industry_performance WHERE comname = 'HPCL' AND sbu_name = 'Retail' AND fiscal_year = '2024-2025') SELECT ROUND(((y2.s2 - y1.s1) * 100.0) / y1.s1, 2) AS sales_growth_percentage FROM y1, y2;
  ```
- **Generated SQL**:
  ```sql
  WITH sales_totals AS (
    SELECT COALESCE(SUM(CASE WHEN industry_performance.fiscal_year = '2023-2024' THEN industry_performance.netweight_tmt ELSE 0 END), 0) AS previous_sales,
           COALESCE(SUM(CASE WHEN industry_performance.fiscal_year = '2024-2025' THEN industry_performance.netweight_tmt ELSE 0 END), 0) AS current_sales
    FROM industry_performance
    WHERE (industry_performance.category != 'O' OR industry_performance.category IS NULL) AND industry_performance.comname = 'HPCL' AND industry_performance.sbu_name = 'RETAIL' AND industry_performance.fiscal_year IN ('2023-2024', '2024-2025')
)
SELECT ROUND(sales_totals.previous_sales::numeric, 2) AS previous_sales_tmt,
       ROUND(sales_totals.current_sales::numeric, 2) AS current_sales_tmt,
       ROUND((sales_totals.current_sales - sales_totals.previous_sales)::numeric, 2) AS sales_difference_tmt,
       ROUND(CASE WHEN sales_totals.previous_sales = 0 THEN NULL ELSE ((sales_totals.current_sales - sales_totals.previous_sales) * 100.0 / sales_totals.previous_sales)::numeric END, 2) AS sales_growth_percentage
FROM sales_totals;
  ```
